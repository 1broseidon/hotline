## Hotline 0.44.1: the composer carries the work

- **What a teammate is doing, where you type.** While it works, the composer's bottom row says so in a few words, with Stop beside it. Press it and the steps grow up inside the composer.
- **Answer without scrolling.** A card waiting on you shows as an amber "Needs you" in the same row and opens right there to be answered.
- **A work pane you can follow.** Each step is a plain heading over what it ran, with its time; opened, its command and output sit in separate blocks.
- **Always know who you're talking to.** With the team rail down to faces, the top bar names the teammate.
