## Hotline 0.42.0

- **ChatGPT and Copilot sign-ins use the vault.** Existing sign-ins move into
  your operating system's credential store when first used, without signing
  you out. If the keychain is locked, Hotline asks you to unlock it and keeps
  the old credential intact until it can finish the move. A served desk using
  `--store file` keeps these tokens in its chosen file store.
- **Downgrading requires sign-in.** Once a sign-in has moved, an older Hotline
  cannot read its credential reference and shows sign-in required. Sign in
  again if you downgrade.
