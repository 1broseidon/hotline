## Description
George's rule (2026-10-15): every tooltip in the UI is 2-3 words, up to 5 where needed. The same goes for status and error labels shown in tight places such as the rail and call cards: a few words, with an info key for the full sentence when more is needed (as the call card's trouble label does).
