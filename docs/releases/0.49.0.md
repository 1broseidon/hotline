## Hotline 0.49.0: one list for every thread, and a window that stays light

- **Lighter and smoother.** A long conversation keeps only what is near the view in the page. With a 2,000-line thread loaded the window uses about half the memory it did, and scrolling, switching teammates and replies landing are smooth on Mac, Windows and Linux. Diagrams draw ahead of time, so scrolling past one no longer stalls.
- **One Threads list.** Every work thread, handoff, subagent, command, pair, call and job is one row in the right-hand pane, opening on what needs you, what is live and the last 24 hours. A Kind menu narrows it.
- **Watch the work.** A subagent, handoff, pair, call, job or command opens in the right pane and shows its work as it happens, with Stop where it can be stopped.
- **Update tracks.** Settings › Updates has a Track: Stable for final releases, or Beta for the betas before them.
- **Fixed:** a long reply no longer stops the conversation updating as it ends; a permission card nobody answers says Expired instead of waiting forever; MCP sign-in no longer reaches into your network for a server on the internet, while servers on your own network or tailnet still sign in; updated SQLite and rmcp for four security advisories.
