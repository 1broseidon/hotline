## Hotline 0.37.0: linked desks, one team across them

- **Link a server's teammates with yours.** In Settings › Desks › Link teammates, link this computer's desk with a server you're connected to. Teammates on both desks see each other and message each other just as teammates on one desk do. The first message still asks you on the receiving desk, and nothing else crosses: no workspaces, tools, secrets or computers.
- **One list of teammates across every desk.** The window shows every desk's teammates in one list, with a desk filter instead of the desk switcher. A teammate on another desk opens without switching, and a desk that's out of reach keeps its teammates listed, dimmed.
- **The server runs on a Raspberry Pi again.** The server edition works on Debian 12 and Raspberry Pi OS bookworm, which 0.36.3 couldn't start on.
- **A user guide that matches the app.** The docs gain a Use Hotline section covering workflows, conversations, side threads, teammates working together, voice and pictures, and the setup pages describe the desk as it is today.
