## Description
Host-cookie lending always asks on a live teammate session's shared desk/phone card. Discovery selects only cookie hosts from private SQLite copies; only Use reads values, bounded to the site's PSL registrable domain and subdomains. Never is per teammate and reversible in Settings. Each accepted lend has a distinct container login and a durable metadata-only removal record; Remove deletes the site's cookies in the container, not the host session. Voice and agent tools cannot approve or read host cookies.
