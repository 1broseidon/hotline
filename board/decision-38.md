## Description
A refused host browser raises one actionable notice per browser per desk run, and leaves otherwise eligible sites retryable.
The notice belongs to the first affected teammate's chat and survives session changes only as desk-lifetime deduplication. Discovery denial is not evidence that a site has no cookies. Settings and chat use the same core-generated remedy, naming the app bundle or actual development executable; readable browsers still offer only through the existing explicit Use card.
