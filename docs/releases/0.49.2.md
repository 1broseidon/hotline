## Hotline 0.49.2: jobs that repeat on the days and at the time you pick

- **A job can repeat on chosen days at a set time.** Ask a teammate for something every weekday at 9:00 and it sets one job that Hotline repeats by itself, on this computer's clock. The job keeps its time through a late run, a restart and the clocks changing. You can add one yourself: in a teammate's Schedules, Add a schedule now offers Once, On days and Every.
- **A run that comes too late is skipped.** When a repeating job's time passed more than two hours before Hotline could run it, because the computer was asleep or Hotline was closed, that run is skipped and its row says so until the next one. A run less than two hours late still runs, and a one-time job still runs whenever Hotline can.
- **Teammates on other agents keep Hotline's tools.** A teammate on another agent, such as Codex, lost every Hotline tool after five minutes without using one, and stayed that way until it was restarted. Its connection to them now lasts as long as the agent does.
- **A time means a time on this computer.** A reminder a teammate set for 9:00 could come hours early or late, because a time written without a zone was read as UTC. It is now read on this computer's clock.
- **A scheduled job is told what it can do.** A job's run was told it could schedule, so a teammate asked for something daily set a one-time job and then could not set the next one from inside it. A run is now told that Hotline repeats its job, or that this is its only run. A run whose agent never listed or used Hotline's tools says so on its thread when it ends.
- **A teammate can make one of its jobs quiet or loud when you ask.** Its own list of jobs now also says which ones you added and which are paused while Background work is off.
- **This version leaves alone what a newer Hotline saved.** If you run a newer version on this desk and then open it with this one again, what the newer version saved about teammates' messages to each other is kept, and files it was holding for them are not deleted.
