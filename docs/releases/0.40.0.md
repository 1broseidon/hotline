## Hotline 0.40.0: relays, and a cleaner house

- **Run a relay on a Raspberry Pi.** `hotline serve --capabilities relay` carries your phone to your desktop and runs no teammates or models. Install it with `--server --relay`, pair a desktop with it as a relay, and choose it under Settings › Remote. Switch the server to agents later and every pairing stays.
- **Pairing away from home just works.** The pairing QR carries your Public address as a fallback, so a phone off your network can pair from the QR alone.
- **Old "needs you" cards go away.** A teammate can withdraw a request it no longer needs, and an unanswered card now expires after 2 hours.
- **Colleagues know each other better.** Teammates see each other's goal, agent, model and capabilities.
- **Clearer when something's wrong.** "Hotline Agent unavailable" when no provider is connected, and a provider refusing turns no longer asks you to sign in again.
- **Faster where it was slow.** Long conversations open quickly, paired desks start side by side, and a slow model list no longer stalls the window.
- **A quality pass under the hood.** Smaller modules, dead code removed, stricter lints, errors that carry their cause, and security patches for rustls, ZIP extraction and the Mermaid bundle.
