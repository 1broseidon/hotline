## Hotline 0.36.2: compatible servers on the Responses API

- **Responses-compatible servers work.** A custom OpenAI-compatible connection on the Responses API, such as Meta's Muse models at `api.meta.ai`, failed every turn with "data did not match any variant of untagged enum StreamingCompletionChunk". Hotline now reads the looser stream these servers send, and logs any part it still can't read so it can be fixed.
