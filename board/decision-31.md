## Description
Files written or edited by a call's own work reach the home chat through the core, stamped From the call. George chose this on 2026-10-21: use successful write/edit tool records, never a directory scan or the model's prose. Within each work result, combine explicit send_file and automatic delivery so each file appears once; up to three files are individual attachments, larger batches are one compact openable/savable list with name, created/edited and size. A later correction is a new work result and may deliver the updated file. The existing workspace reach and revocable call lease still govern reads.
