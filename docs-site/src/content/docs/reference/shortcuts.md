---
title: Keyboard shortcuts
description: Every chord the Hotline window hears.
---

The chord key is <kbd>⌘</kbd> on a Mac and <kbd>Ctrl</kbd> everywhere else.
The same list is in the app: **Help → Keyboard Shortcuts** on a Mac, and
**Keyboard shortcuts** in the **More** menu at the foot of the team list on
Windows and Linux.

## Room

| | |
| --- | --- |
| New teammate | <kbd>⌘</kbd>/<kbd>Ctrl</kbd> + <kbd>N</kbd> |
| Settings | <kbd>⌘</kbd>/<kbd>Ctrl</kbd> + <kbd>,</kbd> |
| Teammate 1 to 9 | <kbd>⌘</kbd>/<kbd>Ctrl</kbd> + <kbd>1</kbd>…<kbd>9</kbd> |

## Conversation

| | |
| --- | --- |
| Search | <kbd>⌘</kbd>/<kbd>Ctrl</kbd> + <kbd>F</kbd> |
| Teammate pane | <kbd>⌘</kbd>/<kbd>Ctrl</kbd> + <kbd>I</kbd> |
| Reply | <kbd>R</kbd> |
| Send | <kbd>Enter</kbd> |
| New line | <kbd>Shift</kbd> + <kbd>Enter</kbd> |
| Interrupt the teammate | <kbd>Esc</kbd> |
| Stop replying, or cancel dictation | <kbd>Esc</kbd> |
| Stop dictating | <kbd>Enter</kbd> |

In search, the arrow keys move through the results and <kbd>Enter</kbd> opens
one.

## Anywhere on this computer

These work from any app, and are set under **Settings → General →
Shortcuts**.

| | |
| --- | --- |
| Dictate (tap, or hold to talk) | <kbd>Ctrl</kbd> + <kbd>Option</kbd>/<kbd>Alt</kbd> + <kbd>H</kbd> |
| Call your agent | off until you set it |
| Call the desk | off until you set it |

Pressing either call shortcut during a call hangs up. See
[Calls and dictation](/docs/use/voice/).

## A teammate's computer

| | |
| --- | --- |
| Paste this computer's clipboard into the desktop | <kbd>⌥</kbd> + <kbd>⌘</kbd> + <kbd>V</kbd> on a Mac, <kbd>Ctrl</kbd> + <kbd>Alt</kbd> + <kbd>V</kbd> elsewhere |

## Panes

| | |
| --- | --- |
| Team: show or hide the team list | <kbd>⌘</kbd>/<kbd>Ctrl</kbd> + <kbd>B</kbd> |
| Close, or step back from a thread to the list | <kbd>Esc</kbd> |
